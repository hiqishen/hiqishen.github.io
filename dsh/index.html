项目列表

地址怎么用，为什么有些项目没有？

有可复制地址

点击卡片的「复制」，粘贴到 DSH 的插件安装框，再按提示安装。多组件会分别列出地址；是否需要额外配置，以作者说明为准。

需按说明安装 / 地址未核实

部分插件需要手动部署或额外配置；未核实、索引标记失效的地址不提供复制。卡片会说明具体原因，并链接项目安装说明。

非直接安装插件

Skill、独立应用、框架和教程属于生态项目，不能统一通过 DSH 的插件安装框使用。按各自仓库说明操作。

来源与日期

每个项目都能追溯

卡片的「来源」链接到实际核对过的 awesome-dsh-plugin.com、dsh.works 或 GitHub 项目。仅同仓库中其他子插件被收录时，不据此标记整个项目。

发布与更新

发布：首次正式 GitHub Release；更新：仓库最后推送时间。按 UTC 显示为 YYYYMMDD。悬浮或键盘聚焦日期可查看说明，「—」表示尚无正式发布或日期未收录。
